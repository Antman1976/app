This is the exact-match hosted build.

Use this if you want the hosted version to match the standalone preview as closely as possible.
It uses one self-contained index.html file and does NOT use a service worker, so old cached files should not keep showing up.

How to host:
- unzip
- upload the contents to Netlify Drop, GitHub Pages, or any static host
- if you already installed an older build on the same domain, remove the old home-screen app and clear site data once before testing this build
